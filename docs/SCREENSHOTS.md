## Contributing Screenshots

If you'd like to contribute screenshots:

1. Run the application: `npm run dev`
2. Take high-quality screenshots (preferably at 2x resolution)
3. Save as PNG format
4. Place in `docs/images/` directory
5. Update this file with image references
6. Submit a Pull Request

### Screenshot Guidelines

- Use a clean, representative state of the application
- Ensure no personal/sensitive information is visible
- Use consistent window sizes (1400x900 recommended)
- Show the most important features
- Include both light and dark modes (when available)
