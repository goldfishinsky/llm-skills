📋 How to Add Custom Skills

1. Click "Open Folder" to access the skills directory

2. Create a new folder for your skill (e.g., my-skill)

3. Add a SKILL.md file with YAML frontmatter

4. Add your script file (Python, Node.js, or Shell)

5. Click "Reload" to load your new skill
